在这里放入照片，文件名对应以下命名（script.js 中已配置）：

【我们的故事】（回忆 + 时间轴合并，照片 + 日期 + 标题 + 文字）：
  memory1.jpg  memory2.jpg  memory3.jpg
  memory4.jpg  memory5.jpg  memory6.jpg
  —— 想加更多回忆：在 script.js 的 memories 数组里复制一行，改成 memory7.jpg 等即可

【高光穿搭图鉴】（单人美照，点击可放大）：
  outfit1.jpg  outfit2.jpg  outfit3.jpg
  outfit4.jpg  outfit5.jpg  outfit6.jpg

支持 jpg / png / webp 格式。改文件名请同步改 script.js 里对应数组的 img / src。

若某张照片还没放，页面会自动显示占位图并标出应放置的文件名。
